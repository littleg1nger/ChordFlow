# 和序 · Chordflow 验证记录

环境：Windows，Node 24.15.0，npm 11.12.1。Git 沿用既有用户配置；未创建远程。

## 阶段 A

`npm run check` 通过：TypeScript、ESLint、22 项乐理测试、Vite 生产构建。依赖已核对官方文档及 npm engines / peerDependencies，使用精确版本及 package-lock。TypeScript 选择 5.9.3 以符合 typescript-eslint 的支持范围。

## 阶段 B

和弦探索与 Web Audio 图已实现。核心测试覆盖需求指定拼写、全部根音 / 类型半音公式、别名大小写、转位集合、斜杠限制与变化音八度。浏览器验证使用本机 Edge 的自动化模式；调度验证不等同于人工听音。

阶段 B：Edge 桌面 1440×1080 与手机尺寸 390×844 的查询、转位、音频节点调度和整页无横向溢出检查均通过，浏览器未捕获 pageerror。未做人工听音或实体手机测试。

## 阶段 C

31 项单元测试通过，包括五种模板、精确小节边界、两手重叠、音区变化、兼容规则及音频时钟暂停 / 继续 / 重复播放 / 预备拍统计。类型检查、lint 与生产构建通过。4 项 Edge 桌面 / 手机尺寸路径测试通过。

## 阶段 D

48 项核心单元测试、类型检查、lint 与生产构建通过。新增四组进行的默认拼写、大小调移调、真实 MIDI 变化、完整声部连接、小节数、JSON 往返与错误数据拒绝。补充了不含纯五度时禁用根五八，以及逐步定位不能虚计完整轮次的测试。

8 项 Edge 桌面 / 手机尺寸路径测试通过：C → D 移调后音名与事件变化、完整四小节播放后的 6 秒记录 / 1 次完成（160 BPM）、保存刷新恢复、复制删除、备份下载并重新导入、拒绝无效版本、小调保留调式、七和弦禁用三音模板。初次失败来自测试的导航选择器匹配到“保存到我的练习”，已改为限定导航区域后通过。

## 阶段 E

14 项 Edge 测试通过，新增 320px 布局、键盘 Enter 触发琴键、后台暂停、减少动态效果、音频失败后重试、本地数据损坏时保留原始值、存储写入失败时继续在内存中操作并导出。浏览器音频分析器检测到非零时域波形（峰值大于 0.001），并记录了振荡器频率与开始调用。这是输出信号 / 调度验证，不是人工听感验收。

已检查桌面与手机截图；播放器独立占据布局空间，工作区内部滚动，不覆盖琴键。增大说明文字，修复窄屏导航换行、隐藏跳转链接在全页截图中溢出、速度输入中途值被过早钳制等问题。没有实体手机、iOS Safari 或人工音箱 / 耳机听音条件。
