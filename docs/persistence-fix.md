# 跨天记录排查与原始数据保护

2026-10-19，收到“第二天练习和时长消失”的反馈。代码没有日期到期、午夜清理或每日重置逻辑，存储 key 仍为 `chordflow:v1`，品牌和配色更新没有变更它。累计时间来自练习播放器的实际运行时间，不含和弦探索试听。

隔离 Edge 上实际保存练习并播放记录时长，将时间从 10 月 18 日深夜切换到 19 日早晨，关闭页面后用同一浏览器上下文重开：练习和统计完整保留。此验证不等于读取了用户平时浏览器中的数据，也不能据此确定本次反馈的原因。浏览器、协议、域名或端口变化、无痕窗口关闭或网站数据清理仍需结合用户访问环境核实。`localhost` 与 `127.0.0.1`、5173 与 4173 的存储分别独立。

确认并复现了一处独立缺陷：任一字段未通过校验时，读取整份数据会失败并回退到默认值；之后普通设置操作会把默认数据写回原 key，覆盖已有练习和累计统计。以保留有效练习和统计、仅将 BPM 改为无效值的样本复现了这一过程。

修复：初始读取失败时保护原始存储，后续设置、收藏、练习与播放记录仅更新内存；持续显示保存异常说明，页眉也显示“仅内存保存”。仅通过现有完整备份校验并主动确认替换，成功写入后才解除保护并恢复自动保存。写入失败仍允许在内存中练习及导出当前数据。导出的当前内存练习不代表原始损坏数据，提示中明确区分两者。未自动合并或修复不可信字段，未更改备份格式。

已被浏览器清除或被旧版本覆盖的数据无法凭空恢复；原网址中仍有的数据或已有 JSON 备份可用于恢复。本轮没有读取、清除或替换用户实际浏览器配置中的记录，测试均运行在隔离上下文。

验证：类型检查、ESLint、61 项核心测试与生产构建通过。浏览器回归中 36 项通过，新增保护流程的 2 项最初因测试样本误带多余字段导致比较失败，改为实际 PracticeConfig 后桌面和手机复测通过。新增跨天重开测试保留练习、秒数及完成轮次；新增保护测试覆盖后续操作不覆盖、导入预览不覆盖、确认替换恢复及刷新后继续保存。

## 用户补充后的排查

用户确认同一浏览器、同一完整网址、普通窗口，未见错误提示，也没有打开多个标签页。不能把上述常见情况或下面复现的独立缺陷认定为其本次丢失的原因；当前缺少实际浏览器中的原始记录，具体原因仍未确认。

另在两个隔离标签页复现：旧页先载入空状态，新页保存练习并实际播放累计时长，旧页修改根音会把新记录覆盖为空。新增写前检查：保存前比对当前存储与本页上一次成功读写的原始字符串，发现其他页面修改或清理时停止自动写回，保留内存供导出，提示刷新读取最新记录。确认导入仍遵循主动替换语义。此检查防止已发生的外部变更被旧页面覆盖，不宣称实现了跨标签页原子事务或自动合并。

在“我的练习”加入“检查本地存储”，只读取并校验当前来源的原始记录，显示存储是否存在、校验失败原因，或有效记录中的练习数、收藏数、累计秒数与轮次；包含当前来源便于核对。不修改原始值，不上传数据，也不显示练习名称。需要用户在其日常浏览器执行此检查后继续定位，自动化测试上下文不能替代用户的实际浏览器数据。
