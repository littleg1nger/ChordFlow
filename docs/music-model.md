# 和序 · Chordflow 音乐模型

C4 = MIDI 60，A4 = 440 Hz。音名字母与变化记号独立于音高类别；例如 E#4 和 F4 是同一琴键，前者必须保留理论拼写。构成音八度按字母推导，不直接拼接 MIDI 的科学八度（B#3 实际 MIDI 60）。

根音固定决定和弦构成；转位只改变声部排列，最低音不一定是根音。斜杠低音只支持和弦内音。右手采用完整构成，左手是根音或显式斜杠低音；不暗中省略七音。

节奏使用整数 tick，四分音符 = 480 tick；4/4 一小节 = 1920，3/4 = 1440。事件包含起点、时长、音符 / MIDI、手别、力度和小节 / 和弦索引。左右手可重叠，以时间轴边界验证小节，不能累计两手时值。

显示、逐步查看与发声使用同一事件序列。Web Audio currentTime 是唯一音乐时钟；requestAnimationFrame 只负责查当前 tick 和短期前瞻调度，不把帧间隔作为节拍。页面隐藏自动暂停。停止清理计划音符与已发声音；暂停在原 tick 恢复，并补奏跨过暂停点的持续音。

平稳连接在有限音区枚举完整转位，通过声部距离及跨度启发式选择；不是所有风格的唯一最优解。移调依调式音阶字母与半音共同推导，不单改和弦标签。

上下行分解与 Alberti 限定三音配置；柱式与三拍子完整支持四音配置；根五八仅限包含纯五度的和弦，不给减 / 增五度和弦擅加纯五度。进行每和弦可持续 1、2、4 小节，所有音型都以本身的 4/4 或 3/4 拍号运行。

Alberti 的左手三音放在右手最低音以下，必要时整体下移八度，避免两手同区密集弹奏。根五八右手在第 1 拍弹完整和弦、只保持一拍，在左手高八度进入前放开。开始 / 恢复播放器会结束逐步查看的短音，避免试听与练习重叠；直接点琴键仍可短暂叠加。

配置连接采用顺序贪心：保留第一和弦原位，然后在 MIDI 52–84（随音区整体平移）内枚举各转位、最大跨度 19 半音，优先最小化相邻有序声部距离；不省略任何构成音。它没有优化跨整组循环回到开头的总距离，也不代表风格最佳配置。

教学来源：各数据条目标注“原创教学示例”；指法只对列出的入门原位给出右手数字及左手根音建议。其他配置不生成所谓标准指法。1 拇指、2 食指、3 中指、4 无名指、5 小指。

## 第二轮扩展

新增八分上 / 下行：三音配置加入最低音高八度作为第四步，四音配置完整依次展开。四音专用分解保留全部四音；十六分音符每个 120 tick，一小节 16 个。反拍在 240、720、1200、1680 tick；交替伴奏左右手在 0、480、960、1440 tick 轮流落下。`1 e & a` 是每拍四个十六分的位置标记，不是音名或手指。

卡农默认 D 大调：D–A–Bm–F#m–G–D–G–A（I–V–vi–iii–IV–I–IV–V）。4536251 默认 C 大调：F–G–Em–Am–Dm–G–C（IV–V–iii–vi–ii–V–I），此处 iii 使用调内小三，不暗中替换为副属 E7。新增爵士 1625 为 Cmaj7–Am7–Dm7–G7。

进行加花仅用于每个和弦的最后一小节，当前限 4/4：

- 右手和弦内音回转：最后一拍改成四个十六分音符，均为当前构成音。
- 右手调内经过音：最后一拍两个八分音符，选取当前大调 / 自然小调中相邻的两个音，逐级走向下一和弦右手最低音；从上下两侧选择移动较少的一侧。
- 左手低音连接：第 3、4 拍用两个四分音符逐级走向下一和弦基本低音。

加花先裁剪 / 替换该声部原事件，再写入新的事件；若另一手在相同琴键上有跨越的持续音，会提前释放共享音，防止争用。基础配置与实际逐步按音分开展示。注释明确区分“加花 · 和弦音”与“加花 · 经过音”，经过音不能被并入理论构成。循环尾部连接回第一和弦；有限循环结束时这一连接表示下一轮的预备，并不额外播放第一个和弦。

自动键盘范围取所有实际演示 MIDI（含加花）的并集，优先三八度且保持留白平衡，跨度过大再扩展；进行播放期间使用整个进行的固定范围。手动范围不改变实际 MIDI，音区外给出恢复自动的入口。

音源是本地采样，说明与许可见 audio.md。旧 v1 设置 / 练习缺少 `fill` 时默认 `none`，设置缺少 `autoRange` 时默认 true；保留原 octave 数值。v1 为向后兼容的可选字段扩展，旧版程序不能识别新进行 / 音型 ID，因此新备份应使用新版本打开。
