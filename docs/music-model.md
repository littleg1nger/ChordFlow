# 和序 · Chordflow 音乐模型

C4 = MIDI 60，A4 = 440 Hz。音名字母与变化记号独立于音高类别；例如 E#4 和 F4 是同一琴键，前者必须保留理论拼写。构成音八度按字母推导，不直接拼接 MIDI 的科学八度（B#3 实际 MIDI 60）。

根音固定决定和弦构成；转位只改变声部排列，最低音不一定是根音。斜杠低音只支持和弦内音。右手采用完整构成，左手是根音或显式斜杠低音；不暗中省略七音。

节奏使用整数 tick，四分音符 = 480 tick；4/4 一小节 = 1920，3/4 = 1440。事件包含起点、时长、音符 / MIDI、手别、力度和小节 / 和弦索引。左右手可重叠，以时间轴边界验证小节，不能累计两手时值。

显示、逐步查看与发声使用同一事件序列。Web Audio currentTime 是唯一音乐时钟；requestAnimationFrame 只负责查当前 tick 和短期前瞻调度，不把帧间隔作为节拍。页面隐藏自动暂停。停止清理计划音符与已发声音；暂停在原 tick 恢复，并补奏跨过暂停点的持续音。

平稳连接在有限音区枚举完整转位，通过声部距离及跨度启发式选择；不是所有风格的唯一最优解。移调依调式音阶字母与半音共同推导，不单改和弦标签。

教学来源：各数据条目标注“原创教学示例”；指法只对列出的入门原位给出右手数字及左手根音建议。其他配置不生成所谓标准指法。1 拇指、2 食指、3 中指、4 无名指、5 小指。
