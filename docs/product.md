# 和序 · Chordflow 产品范围

从和弦开始，弹出自己的伴奏。From chords to accompaniment.

面向中文钢琴初学者，打开直接进入可操作的和弦探索。MVP 闭环为选择和弦、理解构成、观察配置、听转位、学习音型、移调进行、循环练习。

## 本轮交付

- React + TypeScript + Vite 静态应用；无账号、后端、商业 API、远程字体或远程音源依赖。
- 14 类和弦、理论拼写、转位及和弦内斜杠低音；三八度交互钢琴。
- 11 类结构化伴奏、音频时钟播放、暂停继续、左右手、节拍器。
- 7 组进行、同调式移调、原位 / 启发式平稳连接；包含卡农、4536251 与爵士 1625。
- 3 类换和弦前加花及 6 个跟练样例，实际演示所有音高、手别、时值与经过音作用。
- localStorage 设置、收藏、练习和真实播放时间；带版本校验的 JSON 备份。
- 本地验证与 Linux Docker + Nginx 部署文件。服务器信息及上线指令到达前不操作远程。

## 设计决策

1. 默认使用随站点部署的 Salamander MP3 采样，CC BY 3.0、Alexander Holm。只实现轻量单层音源；加载失败明确降级合成音并允许重试。详见 audio.md。
2. 乐理采用小型确定性函数，严格区分音名字母 / 变化记号、音高类别、带八度音符和 MIDI。以测试保护拼写，不引入不必要的运行时库。
3. 切换页面、和弦、音型、调性、音区、速度或手别时停止重置；暂停保留播放位置。仅一个主动会话，琴键短音可叠加。
4. 三音上下行与 Alberti 限三音；专用四音分解限四音，上 / 下行等新增模板支持三 / 四音。根五八还要求有纯五度。add9 同样是四音，不冒充三和弦。
5. 数据仅存在当前浏览器 / 当前来源，设备间不自动同步。导入先完整校验，再一次性替换；导出用于备份。

## 来源与范围

需求来源：最初任务书第一节（当前工作区为用户提供的 `chordflow_prompts.md`）及用户第二轮迭代要求。参考站的可访问文本展示了音名 / 和弦选择、琴键对照、试听及快捷键；仅借鉴功能，不复用品牌、素材或界面。

参考：https://tool.pianoabrsm.com/chord-finder

教学分解、加花、节奏与指法建议均为原创示例；经典进行沿用和声骨架，不含整曲旋律或第三方演奏。音符级钢琴采样的许可见 audio.md。指法是入门建议，不能代替教师按手型与上下文调整。

## 后续范围

多力度钢琴 / 踏板共振、MIDI 输入、自由编排进行、更多拍号及相应加花、九 / 十一 / 十三和弦、开放排列与省略策略。不测量准确率或掌握程度。
