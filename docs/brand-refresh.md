# ChordFlow 品牌与搜索控件修正

本轮按用户反馈，将公开品牌名统一为 **ChordFlow**。旧中文名称、中文字标和 CF 拼字图标不再用于网页；界面的乐理及操作说明继续使用中文。localStorage key、备份格式和已有数据保持兼容。

图标由专门负责图标设计的子代理设计并用 Edge 对比三个方案，选取三条平行上行的圆角声部路径，以蓝绿色 `#157F80` 表达三音叠合与声部流动。没有字母、普通音符或方块背景；检查了 16/24/28/32px 的轮廓和负空间。favicon 使用同一图形，在深色标签栏改用较亮的 `#65C4C0`。

英文 ChordFlow 使用本地 Geist，Flow 部分呼应图标颜色。名称同步到导航、浏览器标题、琴身、帮助及导入错误文案。旧中文字标 SVG、得意黑许可和对应生成步骤移除；现有两个正文 WOFF2 及其许可保持。

| Before | After | Why |
| --- | --- | --- |
| CF 字母拼接、中文与英文分两行 | 蓝绿色三声部图标和 ChordFlow 单行字名 | 品牌名称与音乐含义更统一，小尺寸保持清楚 |
| 搜索含左侧图标、右侧分隔和独立光晕 | 右侧放大镜提交，无分隔线，与选择器同样的焦点轮廓 | 减少一组控件中的视觉差异 |
| 搜索字号 13px，选择器 14px | 桌面统一 14px、38px 高、6px 圆角；焦点 2px、间隔 3px | 浏览器中逐项测得样式一致 |

保留 Enter 和按钮提交、搜索错误提示与所有乐理、音频及保存行为。检查桌面、手机布局及完整功能回归，并执行类型检查、ESLint、核心测试、生产构建和本地生产资源检查。截图见 docs/screenshots/brand.png、controls-focus.png 及探索页三种尺寸截图。

实际验证：`npm run check` 通过（类型检查、ESLint、61 项核心测试、生产构建），`npm run test:e2e` 的 34 项浏览器测试通过。Edge 复查 1366×768、1920×1080 与 390px 手机布局、按键反馈和减少动态效果偏好；生产预览再次验证品牌名称、搜索 Enter/按钮提交和两类控件的焦点样式。`npm run test:smoke` 通过本地字体与图标、30 个 MP3 采样的 MIME/SHA-256、许可与 SPA 回退检查。
