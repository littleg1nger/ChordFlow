# 第二轮：采样、自动音区与更多伴奏

保持原有暖白、墨绿、赭色手别、系统字体 / 等宽音名及钢琴操作台布局。新增内容使用现有控件语言；加花用文字标签和虚线框区分，不只使用颜色。

## 采样阶段

默认切换至 Salamander Grand Piano 单层 MP3 子集，30 个本地文件约 1.92 MiB，CC BY 3.0、作者 Alexander Holm。完整来源、哈希、转换说明与限制见 [音源文档](audio.md)。音频加载进度、失败降级与重试均有真实行为。

验证：51 项核心测试、类型检查、lint 与构建通过；6 项 Edge 桌面 / 手机视口测试通过，包括真实 BufferSource 播放速率、非零波形、采样失败后重试、缓冲区复用、加载期间切页取消发声。没有人工听音结论。

工作区原有任务书删除及新增 chordflow_prompts.md 是用户改动，未纳入功能提交。

## 自动音区阶段

默认依据实际 MIDI 配置选取能容纳全部演示音的三八度视图；跨度超出时适度扩大。进行使用整个时间轴的范围，避免每次换和弦时琴键跳动。保留原有 C2–C5、C3–C6、C4–C7 手动选项，切换和弦和刷新后仍保留手动选择，并可一键恢复自动。显示范围不改变发声音高。

旧 v1 数据缺少 autoRange 时补入 true，保留旧 octave 值，收藏 / 练习 / 记录不变。54 项核心测试通过，覆盖全部根音 / 类型 / 转位的范围包含性、宽跨度、手动范围与旧数据默认值。

## 进行与加花阶段

新增卡农（默认 D 大调）、4536251（默认 C 大调、iii 为 Em）和爵士 1625，合计 7 组。新增八分上行 / 下行、四音分解、交替双手、反拍切分、十六分流动，合计 11 类音型。6 个完整跟练样例可载入、调整和保存。

三类加花分别为和弦内音回转、右手调内经过音、左手低音连接。只在每个和弦最后一小节出现，保持 4/4 边界；先裁剪原事件再替换，必要时释放另一手共享琴键。经过音按当前大调 / 自然小调生成、保留理论拼写，不并入和弦构成。事件和琴键都保留“加花”和手别文字。

旧 v1 数据的 fill 默认为 none，不丢失既有练习。当前加花限 4/4，切到三拍子会回到无加花；非兼容选项禁用。新进行 / 模板 ID 的备份不能交由旧程序读取。

61 项核心测试、类型检查、lint 与生产构建通过，包括新序列、七音保留、十六分位置、加花只在末小节、经过音调内拼写、三个音区边界以及两手共享琴键检查。针对新进行与恢复状态的 10 项 Edge 测试通过。初次全量回归发现加载返回后覆盖后台提示，已加 token 校验修复。自动化对原生 option 使用 disabled 属性校验（本机 Playwright 的 toBeDisabled 未识别 option），原生禁用属性真实存在。

采样声音仍待用户人工听感确认；没有实体手机 / iOS Safari 实测。未执行远程部署。

复查手机琴键截图后，将窄屏白键保持在约 24px，自动模式会将演示按音居中到局部滚动视窗，避免把无关低音区留在首屏；跨度允许时可同时看见左右手。自动定位仅随选择 / 窗口尺寸变化，用户手动拖动不会被播放头抢回。新增针对性浏览器测试验证这一行为。
