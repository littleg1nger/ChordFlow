保持原有暖白、墨绿、赭色手别、系统字体 / 等宽音名及钢琴操作台布局。新增内容使用现有控件语言；加花用文字标签和虚线框区分，不只使用颜色。

## 采样阶段

默认切换至 Salamander Grand Piano 单层 MP3 子集，30 个本地文件约 1.92 MiB，CC BY 3.0、作者 Alexander Holm。完整来源、哈希、转换说明与限制见 [音源文档](audio.md)。音频加载进度、失败降级与重试均有真实行为。

验证：51 项核心测试、类型检查、lint 与构建通过；6 项 Edge 桌面 / 手机视口测试通过，包括真实 BufferSource 播放速率、非零波形、采样失败后重试、缓冲区复用、加载期间切页取消发声。没有人工听音结论。

工作区原有任务书删除及新增 chordflow_prompts.md 是用户改动，未纳入功能提交。

## 自动音区阶段

默认依据实际 MIDI 配置选取能容纳全部演示音的三八度视图；跨度超出时适度扩大。进行使用整个时间轴的范围，避免每次换和弦时琴键跳动。保留原有 C2–C5、C3–C6、C4–C7 手动选项，切换和弦和刷新后仍保留手动选择，并可一键恢复自动。显示范围不改变发声音高。

旧 v1 数据缺少 autoRange 时补入 true，保留旧 octave 值，收藏 / 练习 / 记录不变。54 项核心测试通过，覆盖全部根音 / 类型 / 转位的范围包含性、宽跨度、手动范围与旧数据默认值。
