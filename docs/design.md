# 和序 · Chordflow 视觉与交互规范

## 方向

以练琴桌上的音程笔记为主题：紧凑导航 + 主操作台 + 侧边解释。页面直接可弹奏，不做营销首屏。最突出的元素是宽幅钢琴与其上方的构成音标签，节奏格沿用同一音色和手别语言。

## Tokens

- 纸面 `#F5F5F0`；面板 `#FFFFFF`；文字 `#242E29`。
- 墨绿 `#285846`；边框 `#E1E5DF`；左手赭色 `#A46B48`。
- 右手使用墨绿；声音状态另加实心圆与“响”文字，不能只靠颜色。
- 标题：Georgia / 本地宋体用于少量和弦符号；正文：系统 UI / 微软雅黑；音名数据：Consolas 等宽。
- 8px 基础间距，面板圆角 16px，控件 8px，主控件高至少 40px。

桌面：约 212px 左侧导航，主区域自适应；解释列约 280px。平板取消解释侧列；手机导航变为四项横向导航、设置折行、钢琴仅局部滚动。

## 行为

所有可操作项具备 label、原生按钮或表单语义、清晰焦点。琴键可 Tab 聚焦后 Enter / Space 发声。播放中明确显示当前拍、事件、手别与音名。动效仅用于短暂选中状态，并尊重 prefers-reduced-motion。

错误提示提供恢复动作；存储失败保持当前内存内容并提示导出。音频未解锁时解释需要点击；失败时允许重试。收藏与练习空状态给出可执行入口。
